# Blazor-Scheduler-CRUD-using-custom-adaptor

This application explains the procedures to perform CRUD actions with the [Syncfusion Blazor Scheduler](https://www.syncfusion.com/blazor-components/blazor-scheduler) using [CustomAdaptor](https://blazor.syncfusion.com/documentation/scheduler/data-binding#using-custom-adaptor). It demonstrates how to implement a custom data adaptor for handling Create, Read, Update, and Delete operations efficiently in Blazor applications.

## Overview

The Blazor Scheduler is a powerful component for managing events and appointments in web applications. This project showcases advanced data-binding techniques using a custom adaptor to handle CRUD operations seamlessly. Custom adaptors provide flexibility in data retrieval and manipulation, allowing developers to implement custom business logic for event management.

## Prerequisites

* Visual Studio 2022
* .NET Core 6.0
* Syncfusion Blazor NuGet packages

## Features

* Implement Create, Read, Update, and Delete operations
* Custom adaptor for flexible data handling
* Event scheduling and management
* Data persistence capabilities

## How to run the project

* Checkout this project to a location in your disk.
* Open the solution file using the Visual Studio 2022.
* Restore the NuGet packages by rebuilding the solution.
* Build the solution to ensure all dependencies are resolved.
* Run the project using F5 or the Run command.
