# How to perform CRUD operations in Blazor Scheduler using Custom Adaptor

This application demonstrates how to perform CRUD operations in the [Blazor Scheduler](https://www.syncfusion.com/scheduler-sdk/blazor-scheduler) using a Custom Adaptor. It showcases implementing custom data-binding logic for Create, Read, Update, and Delete actions, enabling flexible data handling and integration of business logic. The sample serves as a practical guide for managing scheduler events efficiently and building dynamic Blazor applications with advanced data interaction.

## Features

* Implement Create, Read, Update, and Delete operations
* Custom adaptor for flexible data handling
* Event scheduling and management
* Data persistence capabilities

## Prerequisites

- Visual Studio 2026 or Visual Studio Code
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## How to run the project

**Visual Studio 2026**:

* Checkout this project to a location in your disk.
* Open the project (`syncfusion-blazor-app.csproj`) file.
* Restore the NuGet packages.
* Run the project.

**Visual Studio Code**:

* Open the repository folder in Visual Studio Code.
* Open the integrated terminal.
* Navigate to the repository root.

```bash
cd Blazor-Scheduler-CRUD-using-custom-adaptor
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
